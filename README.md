# Quran yazı nümunələri

Mədinə məshəfinin **ilk 5 səhifəsi**, açıq mənbələrdən. 30 şrift, hər səhifədə bir nümunə: cəmi **150 nümunə**.

## Mənbələr

| Nə | Haradan | Şərt |
|---|---|---|
| Ərəbcə mətn | [Tanzil Uthmani](https://tanzil.net) | [Lisenziya](https://tanzil.net/docs/license). Mətn olduğu kimi saxlanılıb, hərf dəyişdirilməyib. |
| Səhifə bölgüsü | Mədinə məshəfi, 604 səhifə | Səhifə 1–5: Fatihə 1:1–7, Bəqərə 2:1–29 |
| Şriftlər | [Google Fonts](https://fonts.google.com) | SIL Open Font License |

Şriftlər: Amiri Quran, Amiri, Scheherazade New, Noto Naskh Arabic, Lateef, Harmattan, Markazi Text, Readex Pro, El Messiri, IBM Plex Sans Arabic, Noto Sans Arabic, Cairo, Tajawal, Almarai, Mada, Zain, Fustat, Lemonada, Playpen Sans Arabic, Marhey, Baloo Bhaijaan 2, Katibeh, Noto Nastaliq Urdu, Gulzar, Mirza, Aref Ruqaa, Aref Ruqaa Ink, Noto Kufi Arabic, Reem Kufi, Kufam.

Bu, rəsmi xətt nümunəsi deyil. Hər kart eyni ayələri başqa açıq şriftlə göstərir.
